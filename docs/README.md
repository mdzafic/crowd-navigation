# Dokumentacija
 
Folder sadrži literaturu, bilješke i linkove relevantne za projekat navigacije gomile.
 
| Folder / datoteka | Sadržaj |
|---|---|
| [`model/`](model/) | modeli kretanja i izbjegavanja sudara (Social Force, ORCA) |
| [`paralelizacija/`](paralelizacija/) | radovi o paralelizaciji simulacije gomile na CPU-u i GPU-u |
| [`prostorno-indeksiranje/`](prostorno-indeksiranje/) | prostorne strukture i traženje susjeda (Uniform Grid, cell lists, hashing) |
| [`linkovi-implementacije.md`](linkovi-implementacije.md) | implementacije, dokumentacija i alati |
 
Dio radova opisuje modele i tehnike drugačije od naše implementacije. Koriste se kao literatura za razumijevanje modela, paralelizacije i prostornih struktura, a ne kao direktna implementacijska osnova za sve dijelove projekta.
